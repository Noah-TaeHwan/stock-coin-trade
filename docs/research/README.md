# 리서치 리포트

이 폴더의 리포트는 **합성 데이터**(`src/marketdata/sources/synthetic.py`, 종목명 시드의 결정적 GBM)로 만들었다.
- 실제 시세가 아니다. 실제 시장에서의 전략 성과를 주장하지 않는다.
- 실데이터 소스는 약관을 확인하기 전이라 쓰지 않았다([데이터 소스](../data-sources.md)).
- 각 리포트 첫머리의 명령으로 누구나 같은 파일을 다시 만들 수 있다. 저장소의 파일이 새로 만든 결과와 같은지는 `tests/unit/test_quantlab.py`가 검사한다.

| 리포트 | 대상 | 비용 가정 |
|---|---|---|
| [krx-005930-ma-walkforward.md](krx-005930-ma-walkforward.md) | 005930(합성, 2016~2025, 평일) | 수수료 1.5bp, 슬리피지 5bp, 매도세 0 |
| [crypto-krw-btc-ma-walkforward.md](crypto-krw-btc-ma-walkforward.md) | KRW-BTC(합성, 2018~2025, 매일) | 수수료 5bp, 슬리피지 5bp |

비용은 가정값이다. 코인 수수료 5bp는 거래소 공식 요율을 확인한 값이 아니다.

## 읽는 법

두 리포트 모두 이동평균 교차 전략의 (fast, slow) 20쌍을 비교한다. 검증 구간 전체(3번 표)에서 결과는 다음과 같다.

| | 005930 | KRW-BTC |
|---|---|---|
| 사후 최적(전체 기간을 보고 고름) | +51.41%, Sharpe 0.40 | −31.53%, Sharpe −0.02 |
| 워크포워드(학습 구간에서만 고름) | +15.84%, Sharpe 0.21 | −62.66%, Sharpe −0.29 |
| 매수 후 보유 | −3.79%, Sharpe 0.12 | −84.40%, Sharpe −0.24 |

- **사후 최적이 워크포워드보다 좋은 이유**: 사후 최적은 결과를 본 뒤 고른 파라미터다. 같은 구간에서 실제로 얻을 수 있었던 성과는 워크포워드 쪽이다. 두 숫자의 차이가 최적화 편향의 크기다.
- **워크포워드가 매수 후 보유보다 좋은 이유**: 이 합성 가격은 수익률이 서로 독립인 GBM이다. 이동평균 신호가 미래를 예측할 구조가 없다. 차이는 하락 구간에 현금을 들고 있었던 우연과 노출도 차이로 보는 것이 맞다. 전략의 우위로 해석하면 안 된다.
- **구간마다 고른 파라미터가 바뀐다**: 2번 표에서 선택이 5/60 → 20/200 → 30/200으로 바뀐다. 한 쌍이 안정적으로 선택되지 않는다는 것도 과최적화의 신호다.

이 리포트가 보여 주려는 것은 전략의 수익성이 아니다. **같은 엔진·데이터·비용에서 표본 내 최적화가 얼마나 낙관적으로 보이는지**를 재현 가능하게 측정하는 절차다. 약관이 확인된 실데이터가 생기면 같은 명령에 소스만 바꿔 다시 돌린다.
