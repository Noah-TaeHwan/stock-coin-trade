# 코인 차익·김프(ARB) 화면 검증 — 2026-09-24

대상은 브랜치 `claude/loving-planck-cuh4xn`이고, 기준은 `main`의 `2e7bab4`다. 새 화면 1개와 백엔드 Blueprint 1개를 추가했고, 기존 화면은 공통 셸에 메뉴 1개와 명령 1개만 더했다.

## 무엇을 만들었나

| 영역 | 내용 |
|---|---|
| 백엔드 `arbitrage.py` | `/api/arb/snapshot`: 원화 거래소 4곳(업비트·빗썸·코인원·코빗)과 해외 거래소 2곳(OKX·Binance)의 시세, 김프(USDT 기준·환율 기준), USDT 프리미엄, 국내 최대 가격 차이, 소스별 상태. |
| | `/api/arb/{coin}/matrix`: 호가창을 VWAP으로 따라가며 "A에서 N원 매수 → B로 전송 → 매도"를 모든 거래소 쌍에 대해 계산한다. 테이커 수수료·출금 수수료를 뺀 순손익, 호가 깊이 부족 여부, 빗썸 입출금 상태를 준다. |
| | `/api/arb/{coin}/history`: DB 없이 캔들로 김프 추이를 복원한다. 식은 업비트 KRW 종가 ÷ (OKX USDT 종가 × 업비트 KRW-USDT 종가) − 1이다. |
| | `/api/arb/network`: 코인별 네트워크·블록 시간·확인 수·예상 전송 시간·출금 수수료 참고값, 거래소 수수료, mempool.space 기준 BTC 온체인 비용. |
| 화면 `arbitrage.html` | 터미널 3열 구성이다. |
| | 왼쪽: 코인별 김프 목록(정렬 가능). |
| | 가운데: 환율·USDT 지표 띠, 김프 추이(0% 기준 baseline 차트, 1H/1D), 도크 탭(순스프레드 매트릭스·거래소별 김프·전송·수수료·소스 상태). |
| | 오른쪽: 차익 시뮬레이터(금액·거래소·수수료·출금 수수료 입력)와 실행 전 확인 사항(트래블룰·외국환거래법·입출금 중단). |
| 공통 셸 `common.js` | 명령 `ARB`·`KIMP`를 추가했다. `ARB ETH`처럼 코인을 인자로 받을 수 있다. 거래 메뉴에 "코인 차익·김프"를 추가했다. |
| 설계 원칙 | 공개 시세만 쓰고 주문·출금 기능은 없다. 소스 하나가 실패하거나 지역 제한에 걸려도 나머지로 계산하고, 화면에 소스별 상태를 표시한다. 외부 API 부하를 막기 위해 시세·호가는 5초, 캔들은 60초, 환율은 1시간 캐시한다. |

수수료와 출금 수수료는 기본 등급 기준 참고값(기준일 2026-09-24)이다. 등급·쿠폰·네트워크에 따라 달라지므로 시뮬레이터에서 직접 고칠 수 있게 했다. 업비트·코인원·코빗·OKX의 지갑 상태와 출금 수수료는 인증 API라서 "확인 필요"로 표시한다.

## 실행 환경

- 클라우드 작업 컨테이너: Docker 29.3.1, Compose v5.1.1, x86_64.
- [PORTFOLIO_LOCAL.md](../../PORTFOLIO_LOCAL.md) 절차로 `.env.portfolio`를 만들고, 같은 Compose 명령으로 네 서비스(mariadb·postgres·python-backend·frontend)를 올렸다. 네 서비스 모두 healthy였다.
- 이 컨테이너에서만 저장소 밖 임시 파일을 썼고, 커밋하지 않았다.
  - 백엔드 Dockerfile 사본: `docker/python-backend.Dockerfile`에 작업 환경의 TLS 재종단 CA만 추가했다. 사내 프록시가 없는 로컬 PC에서는 필요 없다.
  - Docker Hub가 `429 Too Many Requests`를 반환했다. 그래서 같은 공식 이미지(`mariadb:11.4`, `postgres:16-alpine`, `nginx:alpine`)를 `mirror.gcr.io/library`에서 받아 같은 이름으로 태그했다.
  - Playwright는 CDN 스크립트(Tailwind, lightweight-charts)를 Node 쪽에서 받아 브라우저에 넘겼다. Node는 작업 환경 CA로 TLS를 검증하고, 검증을 끄지 않았다.
- 브라우저: Playwright 1.56.1 + Chromium, 로캘 `ko-KR`, 시간대 `Asia/Seoul`. 비로그인 상태로 확인했다. 이 화면은 공개 시세라 로그인이 필요 없다.
- 이 컨테이너(미국 위치)에서는 Binance가 `HTTP 451`, Bybit가 CloudFront `403`으로 막힌다. 그래서 해외 기준가는 OKX를 기본으로 쓰고, Binance는 차단되면 `blocked`로 표시한다. 한국에서 실행하면 Binance도 함께 계산된다.

## 한계

- 수수료·출금 수수료·확인 수는 참고값이다. 실제 값은 거래소 화면과 공식 안내에서 확인해야 한다.
- 김프 추이는 1시간·1일 봉의 종가를 맞춘 값이다. 거래소마다 마지막 체결 시각이 달라서 1시간 봉은 ±0.2% 정도 흔들린다.
- 해외 거래소 구간은 USDT를 업비트 가격으로 환산한다. 원화↔USDT 환전 비용과 해외 송금 규제는 계산에 넣지 않았다.
- 차트 canvas 안의 글자는 대비 계산에서 빠진다. 스크린샷을 직접 보고 확인했다.
