# S2 데이터 이용조건 조사 — 공식 페이지 사실 정리

- 작성: Legal Compliance Checker(팀원) · 접근일: 모든 URL 2026-09-26 · 저장소 파일은 수정하지 않았다(읽기만).
- 이 문서는 조항에 적힌 내용과 불명확한 점만 정리했다. 합법인지 위법인지는 판단하지 않는다.
- 인용은 출처마다 한 구절(15단어 미만)로 제한했고, 나머지는 요약이다.
- 상태 표기
  - **확인**: 공식 페이지 원문을 직접 읽었다.
  - **확인(요약)**: WebFetch 소형 모델 요약으로만 읽었고 원문과 대조하지 않았다.
  - **미확인**: 읽지 못했거나 읽은 페이지에 해당 내용이 없다.
- 읽은 경로(근거란의 대괄호)
  - **[curl]**: 공식 페이지 HTML을 그대로 받아 텍스트로 바꿔 읽었다(요약 없음). 서버가 HTML로 본문을 주는 페이지에 썼다.
  - **[WebFetch]**: WebFetch 요약. 이번 보고서에서 WebFetch만으로 확인한 항목은 빗썸 공지 API의 응답 필드와 '인증 없음' 두 가지다.
  - **[Playwright]**: 헤드리스 Playwright로 본문 텍스트를 읽었다. JS로 렌더링되는 약관 페이지에 썼고, Ego 사용 지침을 받기 전에 사용했다.
  - **[Ego]**: ego-browser TaskSpace "S2 데이터 권한 조사"(spaceId 2)로 읽었다. 지침을 받은 뒤 WebFetch 요약 항목을 원문으로 다시 확인하고 미확인 항목을 채우는 데 썼다. 끝난 뒤 `finish({ keep: [] })`로 닫았다.
  - **[GitHub]**: 라이브러리 원본 소스(raw.githubusercontent.com, `gh api`).

## 3. S1~S3 후보

해석: S1~S3를 목적에 적힌 세 가지 데이터 수요로 읽었다. S1 = 주식 일봉, S2 = 공시 목록, S3 = 코인 시세·공지. 아래는 조항 문언이 무엇과 맞닿는지만 적는다. 쓸 수 있는지는 노아가 판단한다.

| 수요 | 소스 | 무료 공개 베타 | 유료 기능 추가 뒤 | 근거 조항 |
|---|---|---|---|---|
| S1 주식 일봉 | data.go.kr 주식시세정보 | 금지 문언과 맞닿음 | 금지 문언과 맞닿음. 유료 구매 경로 안내가 따로 있다 | 설명란 재배포 금지 문장, 공공누리 4유형(상업금지·변경금지) |
| S1 | KRX Open API | 해석 필요(제3자 제공 금지 vs 화면 출처 표시) | 비상업 조항과 직접 맞닿음 | 제6조②, 제10조③, 제11조② |
| S1 | KIS(개인 키) | 금지 문언과 맞닿음 | 금지 문언과 맞닿음 | 개인 약관 제5조③, 서비스 소개 ※ 주석 |
| S1 | KRX 웹 수집(pykrx·FDR), 네이버 | 자동화 수집 금지 문언, robots Disallow | 같음 | KRX 홈페이지 약관 제10조②·제12조②, 네이버 약관 자동화 수단 항목, robots.txt |
| S1 | **남은 경로(조건 미확인)**: KRX 마켓데이터 상품 구매 / 코스콤 등과 시세정보이용계약 | 약관·비용 미확인 | 약관·비용 미확인 | data.go.kr 설명란의 구매 안내, KRX 홈페이지 약관 제12조의2, KIS 서비스 소개 ※ 주석 |
| S2 공시 목록 | **OpenDART** | 상업·재배포를 제한하는 조항을 찾지 못함 | 같음(단, 제11조① 유료화 가능성) | 약관 제5·16조④(공공데이터법 준용), data.go.kr 1유형(출처표시), 제19조②(인증키), 제23조①(정확성 비보장) |
| S3 코인 시세 | 업비트 | '무단 배포' 문언과 맞닿음 | '영리목적 이용 금지' 문언과 직접 맞닿음 | Open API 약관 제5조, 업비트 이용약관 제10조 |
| S3 | 빗썸 시세 | '양도'의 범위에 따라 다름 | 일반 약관의 '유사 서비스·상업적 활동 금지'와 맞닿음 | API 약관 제6조①, 일반 약관 제11조·제14조 |
| S3 코인 공지 | 빗썸 공지(제목·분류·시각·링크) | 제6조① 적용 대상인지 불명확 | 일반 약관 제11조와의 관계 불명확 | API 약관 제6조①, 일반 약관 제11조 |

요약:
- **S1**: 무료 베타와 유료 확장 모두에서 조항과 부딪히지 않는 무료 공식 소스를 찾지 못했다. 공식 페이지가 안내하는 경로는 KRX 유료 상품 구매나 코스콤 등과의 시세정보이용계약이다. 둘 다 약관과 비용은 확인하지 못했다.
- **S2**: OpenDART만 제한 조항이 보이지 않았다. 출처 표시(1유형)와 인증키 조항이 조건으로 남는다.
- **S3**: 업비트·빗썸 모두 허락 없이 공개·유료로 쓰는 경우를 명시적으로 허용하는 조항을 찾지 못했다. 업비트는 2024-10-30 개정으로 '영리목적 이용 금지'가 추가됐다.

## 6. 조사 한계

- 법률 해석이나 결론은 없다. "맞닿는다", "불명확하다"는 조항 문언을 비교한 결과이고, 효력이나 적용 여부를 판단한 것이 아니다.
- 읽지 못한 것(미확인)
  - data.go.kr 활용자가이드(docx 다운로드 금지 조건) → 수정주가 여부 미확인.
  - KRX 「마켓데이터 상품 구매 및 이용약관」과 상품 가격. KRX 홈페이지의 이용안내·데이터 상품 소개 페이지를 curl과 Ego로 열었지만 약관·가격 텍스트가 없었다. 구매 흐름은 로그인이 필요해 들어가지 않았다.
  - KRX Open API 서비스 목록·데이터 제공 시점, 영문 약관.
  - KIS 수수료 금액, 제휴 FAQ.
  - KIND(kind.krx.co.kr) 약관, 코스콤 시세정보이용계약 조건, 공공누리 유형 정의 원문(kogl.or.kr), 공공데이터법 조문.
- WebFetch 요약에만 의존한 항목은 빗썸 공지 API의 응답 필드와 '인증 없음'뿐이다. 처음 요약으로만 확인했던 업비트 rate limit 문서, 업비트 개발자센터 문구, 빗썸 공지 API 호출 한도는 Ego로 원문을 다시 읽어 확인으로 올렸다.
- Ego로 연 docs.upbit.com과 apidocs.bithumb.com은 영문으로 렌더링됐다(`lang=en`). 영문 원문과 WebFetch 한국어 요약의 수치는 같았다.
- JS 렌더링 약관(업비트 Open API·이용약관, 빗썸 API·이용약관, KIS 약관)은 Ego 지침을 받기 전에 헤드리스 Playwright로 읽었다. 이 가운데 업비트 Open API 약관 제5조·적용일은 Ego로 다시 대조했다. 나머지는 Ego로 다시 읽지 않았다.
- 로그인·폼 제출·약관/쿠키 동의·다운로드는 어느 경로에서도 하지 않았다. KIS 약관은 페이지의 "이용약관"·"제휴기관 이용약관" 링크를 눌러 열리는 창에서 읽었고, KIS 유량 공지는 공지 목록에서 제목을 눌러 열었다(동의 행위 없음).
- 빗썸 약관은 페이지가 기본으로 연 판(일반 약관 2026-09-01, API 약관 2020-03-27)만 읽었다. 이전 판과는 비교하지 않았다.
- 업비트 현행판 제3·4조: Ego로 docs.upbit.com에 실린 본문 일부(제3조⑤⑦⑨, 제4조①③④)를 읽었고 2023-12-15판과 문언이 같았다. 제2조 메모에 쓴 제3조②는 2023판에서만 확인했다.
- 모든 내용은 2026-09-26 시점의 스냅샷이다. 각 약관에는 개정·공지 조항이 있어 바뀔 수 있다.
- API 키 사용과 회원가입은 하지 않았다. 키 없이 호출한 것은 robots.txt와 공개 웹페이지뿐이다.
- 작업 흔적
  - Playwright가 저장소의 `.playwright-mcp/`(gitignore 대상)에 남긴 이번 세션 파일 12개는 파일명을 지정해 지웠다. 이후 `git status`는 깨끗했다.
  - Ego TaskSpace는 에이전트가 연 탭(p1) 하나만 있었고 `finish({ keep: [] })`로 닫았다. 사용자 탭과 기존 space는 건드리지 않았다.
