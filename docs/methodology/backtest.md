# 백테스트 방법론 (`src/quantlab`)

`POST /api/quant/backtests`와 `python -m quantlab.research`가 쓰는 계산 규칙이다. 코드는 Flask·DB에 의존하지 않는 `src/quantlab`에 있고, 규칙마다 아래 표의 테스트가 고정한다.

## 0. 입력 데이터

- 백테스트는 PostgreSQL `market_data`에 저장된 일봉을 읽는다.
- 봉마다 `source`가 있다. `config/data_sources.toml`이 현재 프로필에서 켜 둔 소스의 봉만 쓴다.
  - 켜지지 않았거나 레지스트리에 없는 소스가 섞이면 403으로 거절한다.
  - 수집 CLI도 같은 레지스트리를 확인한다. 그래도 SQL 시드나 복원한 덤프처럼 다른 경로로 들어온 행이 있을 수 있어서, 데이터를 쓰는 지점에서도 한 번 더 확인한다.
- public에서 켜진 소스는 합성 데이터 두 가지뿐이다.
  - `synthetic`: 결정적 GBM
  - `synthetic_sql`: `database/quant-postgres.sql`의 학습용 사인파 샘플

## 1. 시간 순서

봉 t마다 다음 순서로 계산한다(`engine.py`).

1. **t 시가**: t−1 종가에서 정한 목표 포지션을 체결한다.
2. **t 종가**: 계좌를 평가한다(현금 + 보유 수량 × 종가).
3. **t 종가**: 전략이 t까지의 데이터로 다음 목표 포지션을 정한다. 이 목표는 t+1 시가에 체결된다.

마지막 봉의 목표는 다음 시가가 없어 체결하지 않는다. 기간이 끝날 때 보유 중인 포지션은 강제로 청산하지 않고 종가로 평가한다.

신호를 낸 봉에서 바로 체결하지 않으므로, 신호 계산에 쓴 종가로 거래할 수 없다. 테스트는 두 가지로 확인한다.
- 미래 데이터를 잘라도 그 이전 포지션·자산이 바뀌지 않는다(Hypothesis 속성 테스트).
- 첫 매수가 신호 다음 봉의 시가 × (1 + 슬리피지)다.

## 2. 비용

모든 비용은 bp(0.01%)로 받는다(`engine.Costs`).

| 항목 | 적용 | 기본값 |
|---|---|---|
| 수수료 `fee_bps` | 매수·매도 체결 금액에 각각 | 1.5bp |
| 슬리피지 `slippage_bps` | 매수는 시가 × (1 + s), 매도는 시가 × (1 − s) | 5bp |
| 매도세 `sell_tax_bps` | 매도 체결 금액에만 | 0bp |

- 매도세(증권거래세)는 기본 0이다. 현재 세율과 적용일을 공식 출처로 확인하기 전까지 값을 넣지 않았다. 필요하면 요청에서 `sellTaxRate`로 지정한다.
- 수수료·슬리피지 기본값은 기존 화면이 쓰던 값(0.015%, 0.05%)이다. 특정 증권사·거래소의 실제 요율이 아니다.
- API는 화면과의 호환을 위해 비율(`feeRate: 0.00015`)을 받아 bp로 바꾸고, 부동소수 오차가 영수증 ID를 바꾸지 않도록 소수 6자리로 반올림한다.

## 3. 포지션 크기

- 롱 온리, 한 종목, 보유(1) 또는 현금(0)이다.
- 매수는 가용 현금을 모두 쓴다. 수량은 `현금 / (체결가 × (1 + 수수료))`의 내림이다.
  - KRX 종목: 정수 주
  - 코인(`KRW-BTC`처럼 `-`가 있는 심볼): 소수 8자리
- 초기자본 기본값은 1,000만 원이다(`initialCapital`로 변경).
- 매수 후 보유 벤치마크는 같은 비용으로 첫 시가에 사서 끝까지 보유한다.

## 4. 지표

모든 지표는 **봉마다 평가한 자산곡선**에서 계산한다(`metrics.py`). 거래가 없는 날도 수익률 0으로 포함한다.

| 지표 | 정의 |
|---|---|
| 일수익률 r | 자산의 봉 간 변화율 |
| 총수익률 | 마지막 자산 / 첫 자산 − 1 |
| CAGR | (마지막 / 첫)^(연 봉 수 / (봉 수 − 1)) − 1 |
| 연 변동성 | std(r, ddof=1) × √연 봉 수 |
| Sharpe | mean(r − rf/연 봉 수) / std(같은 값, ddof=1) × √연 봉 수. rf 기본 0 |
| Sortino | mean(초과수익) / √mean(min(초과수익, 0)²) × √연 봉 수 |
| MDD | min(자산 / 누적 최고 자산 − 1). 보유 중 낙폭 포함 |
| Calmar | CAGR / \|MDD\| |
| 노출도 | 포지션을 보유한 봉의 비율 |
| 승률 | 청산(매도) 거래 중 순손익 > 0 비율 |
| 회전율 | 총 체결 금액 / 평균 자산 |

- 연 봉 수는 KRX 252, 코인 365다(`marketdata.calendars`).
- 표준편차가 1e-12 미만이면 Sharpe·Sortino는 정의하지 않고 `null`로 둔다. 부동소수 잡음이 비율을 좌우하기 때문이다.
- 지표는 테스트에서 별도로 작성한 numpy 공식과 비교한다. 처음 계획한 empyrical-reloaded는 런타임 lock의 peewee 4.5.1과 충돌해(`peewee<3.17.4` 요구) 설치하지 않았다.

## 5. 지표 창

- 이동평균·RSI·모멘텀은 창이 다 찰 때까지 값이 없다(NaN). 예를 들어 50일 이동평균은 50번째 봉부터 값이 있다.
- 값이 없는 동안에는 비교가 거짓이라 신호가 나지 않는다.
- 돌파 전략의 "직전 20일 최고가·평균 거래량"은 오늘 봉을 제외한다.
- RSI는 Cutler 방식(상승·하락폭의 단순 평균, 14봉)이다.

## 6. 전략

| id | 규칙 | fast/slow |
|---|---|---|
| `ma2050` | fast 이평이 slow 이평을 상향 돌파하면 매수, 하향 돌파하면 매도 | 20/50 |
| `trend` | 같은 규칙 | 5/20 |
| `pullback` | fast > slow인 상태에서 종가가 fast 이평을 상향 돌파하면 매수, fast < slow면 매도 | 20/60 |
| `rsi` | RSI(14)가 30을 상향 돌파하면 매수, 70을 하향 돌파하면 매도 | 사용 안 함 |
| `breakout` | 종가 > 직전 20일 최고가이고 거래량 > 직전 20일 평균이면 매수, 종가 < 10일 이평이면 매도 | 사용 안 함 |
| `momentum` | 60일 수익률 > 0이고 종가 > 60일 이평이면 매수, 하나라도 깨지면 매도 | 사용 안 함 |

fast/slow는 `2 ≤ fast < slow ≤ 250`이어야 한다. 이 범위를 벗어나거나 알 수 없는 전략이면 400을 반환한다.

## 7. 계산 영수증

실행마다 영수증을 만든다(`receipts.py`).

- **포함 항목**: 입력 봉의 sha256, 파라미터 전체(비용·초기자본·연 봉 수 포함), 엔진 버전, 데이터 출처, 첫·마지막 봉, git 커밋.
- **영수증 ID**: sha256(엔진 버전 + 입력 해시 + 파라미터)다. git 커밋은 기록하지만 ID에는 넣지 않는다.
- **멱등 저장**: `backtest_runs`의 기본키가 영수증 ID다. 같은 입력으로 다시 실행하면 새 행을 만들지 않고 저장된 실행(`strategyId`, 처음 기록한 git 커밋)을 200으로 돌려준다. 새 실행은 201이다.

엔진의 계산 방식을 바꾸면 `quantlab.ENGINE_VERSION`을 올린다. 그래야 같은 입력이라도 다른 영수증이 된다.

## 8. 워크포워드 검증

`validation.walk_forward`는 다음 순서로 동작한다.

1. 학습 구간에서 후보 (fast, slow) 쌍을 모두 실행하고, Sharpe가 가장 높은 쌍을 고른다.
2. 고른 쌍을 바로 다음 검증 구간에서 실행한다.
3. 검증 구간 길이만큼 앞으로 옮겨 반복한다. 검증 구간은 서로 겹치지 않는다.

- 검증 실행은 처음부터의 이력으로 지표를 계산하되, 검증 구간의 봉만 평가한다.
- 학습 구간 마지막 종가의 목표 포지션은 검증 구간 첫 시가에 체결한다.
- 검증 구간들의 봉 간 수익률을 이어 붙여 하나의 표본 외 자산곡선을 만든다. 이때 두 구간 사이의 1봉 수익률은 포함하지 않는다.

리포트(`python -m quantlab.research`)는 같은 데이터에서 세 가지를 나란히 보여 준다.
- 기본 파라미터
- 전체 기간을 보고 고른 사후 최적 파라미터
- 워크포워드

결과는 [docs/research](../research/README.md)에 있다.
