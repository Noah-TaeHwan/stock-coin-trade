PINE SCRIPT GUIDE

Pine Script란 무엇인가요?

Pine Script는 TradingView 차트에서 지표와 전략을 만드는 전용 언어입니다. 이 웹앱에서는 주요 전략 신호를 학습·모의주문에 활용할 수 있지만, Pine Script 전체를 직접 실행하는 환경은 TradingView입니다.

TradingView 열기 ↗Pine 전략 테스트하기

TradingView에서 사용하는 순서

별도 프로그램을 설치하지 않고 웹 브라우저에서 Pine Script를 작성하고 차트에 적용할 수 있습니다.

1
TradingView에 접속해 차트를 엽니다.

원하는 시장과 종목을 선택합니다.

2
차트 하단의 Pine Editor를 선택합니다.

코드를 작성하거나 기존 전략을 수정합니다.

3
Add to chart를 눌러 적용합니다.

지표, 매수·매도 신호, 전략 테스터 결과를 차트에서 확인합니다.

Pine 신호로 자동매매를 연결하는 일반적인 방식

Pine Script가 증권사나 거래소에 직접 주문을 보내는 것은 아닙니다. 일반적으로 TradingView 알림의 웹훅을 외부 서버가 받아, 거래소·증권사 API로 주문을 전달합니다.

TradingView 전략·알림→Webhook→외부 서버 (Python 등)→거래소·증권사 API

실거래 자동화에는 API 키 보관, 주문 중복 방지, 예외 처리, 손실 한도와 모니터링이 필요합니다. 이 웹앱의 Pine 전략 거래는 실거래가 아닌 학습용 모의주문입니다.
