KIS 모의 주문 흐름 테스트

서버가 KIS Testbed에서 삼성전자 1주 저가 지정가 주문을 내고, 즉시 정정한 뒤 취소합니다. App Key·Secret·계좌번호·접근 토큰·주문번호는 브라우저로 전송하지 않습니다.

LOGIN · APPROVAL
FLOW실행 내용주문 → 정정 → 취소
1. 안전 조건 확인현재가를 조회해 그 90%(호가 단위 내림)를 지정가로 계산합니다. 정정 가격은 거기서 한 호가 아래입니다. 현재가가 0원이거나 충분히 낮은 가격을 만들 수 없으면 주문을 보내지 않습니다.
2. Testbed 모의 주문 → 정정 → 취소모의투자 전용 거래 ID를 사용합니다. 정정이 실패해도 원주문 취소를 시도하고, 취소가 실패하거나 정정 결과가 불확실하면 오늘 미체결을 조회해 남은 주문을 모두 취소합니다. 동시에 두 번 실행되지 않습니다.
3. 결과만 표시주문·정정·취소 각 단계의 성공·실패와 사유만 표시합니다. 주문번호·계좌·키는 표시하지 않으며 실제 자금 거래 및 실전 서버 호출은 하지 않습니다.

호출 경로: 브라우저 → 이 저장소 백엔드 POST /api/broker-test/kis/order-flow-test → KIS Testbed trading/order-cash → order-rvsecncl (VTTC0012U·VTTC0013U). 브라우저가 KIS 를 직접 호출하지 않으며 키·토큰은 백엔드에만 있습니다. 자세한 표는 3단계 · 테스트의 "호출 경로" 참고.
