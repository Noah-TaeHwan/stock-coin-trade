데이터로 판단하는 투자자를 위한 도구 · 투자 조언이 아닙니다

개인정보 처리방침

버전 2026-09-26 · 시행일 2026년 9월 26일. 가입할 때 동의한 버전은 계정에 기록됩니다.

Noah Trading Desk(이하 "서비스")를 개인으로 운영하는 오태환(이하 "운영자")은 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 정합니다. 운영자는 서비스 제공에 필요한 최소한의 개인정보만 처리합니다.

1. 처리 목적, 항목, 보유 기간

  • 회원 가입·로그인·계정 관리
    항목: 이메일 주소, 닉네임, 비밀번호(복원할 수 없는 해시로만 저장), 가입·메일 인증 시각, 동의한 처리방침 버전과 시각, 만 14세 이상 확인, 로그인 세션 정보(세션 값의 해시, 발급·마지막 사용 시각), 메일 인증·비밀번호 재설정 링크 값(해시)
    보유: 탈퇴할 때까지. 가입 후 7일 안에 메일 인증을 마치지 않은 계정은 삭제합니다. 로그인 세션은 마지막 사용 후 7일 또는 발급 후 30일이 지나면 삭제합니다.
  • 모의투자·백테스트 등 서비스 제공
    항목: 모의투자 주문·보유 내역과 가상 예수금, 관심 종목 메모, Open API 키 정보(키의 해시·앞자리·이름표·마지막 사용 시각), 외부 API 테스트 이력(제공사, 사용한 기능, 민감한 값을 가린 요청·응답 요약)
    보유: 탈퇴할 때까지. 외부 API 테스트 이력은 90일 뒤 삭제합니다.
  • 모의투자 랭킹 공개
    공개 항목: 닉네임, 모의 총자산, 모의 수익과 수익률(상위 10명). 이메일은 공개하지 않습니다. 랭킹에서 빠지기를 원하면 아래 개인정보 보호책임자에게 요청해 주세요.
  • 보안 유지와 오류 진단
    항목: 서버 접속 기록(IP 주소, 접속 시각, 요청 주소, 응답 코드, 이전 페이지 주소, 브라우저 정보) — 회원과 비회원 모두. 오류 기록(IP 주소, 브라우저 정보, 요청 경로, 오류 내용, 회원 번호)
    보유: 서버 접속 기록 30일, 오류 기록 90일 뒤 자동 삭제. 탈퇴하면 오류 기록과 회원 번호의 연결을 먼저 끊습니다.
  • 이용 통계
    항목: 서비스를 이용한 날짜(하루 한 줄). 이 기록에는 시각·기기·접속 위치를 넣지 않습니다.
    이용: 주간 이용자 수처럼 개인을 드러내지 않는 합계로만 봅니다. 보유: 탈퇴할 때까지.

처리 근거: 회원 가입·로그인·서비스 제공과 랭킹 공개는 가입 때 받는 필수 동의(「개인정보 보호법」 제15조제1항제1호)와 서비스 제공 계약의 이행(같은 항 제4호)에 따릅니다. 보안 유지와 오류 진단을 위한 접속·오류 기록은 운영자의 정당한 이익(같은 항 제6호)에 따르며, 이용 통계는 개인을 드러내지 않는 합계로만 봅니다. 명령 바의 국외 이전은 아래 4절의 별도 동의에 따릅니다. 운영자는 위 목적 밖으로 개인정보를 이용하지 않으며 마케팅 메일을 보내지 않습니다. 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법률에 특별한 규정이 있는 경우(예: 수사기관의 영장)에는 요청 범위 안에서 제공할 수 있습니다.

2. 파기 절차와 방법

  • 보유 기간이 지나거나 처리 목적을 이룬 개인정보는 지체 없이 파기합니다. 다른 법령에 따라 보존해야 하는 개인정보는 현재 없습니다.
  • 회원이 탈퇴하면 회원 정보와 서비스 이용 중 만든 정보를 한 번에 삭제합니다. AI 기능 사용 비용 기록은 월 예산 관리를 위해 합계만 남기고, 회원 번호와 초대 코드 이름표를 지워 누구의 기록인지 알 수 없게 합니다.
  • 메일 인증을 7일 안에 마치지 않은 계정과 90일이 지난 오류·외부 API 기록은 매일 새벽 자동으로 삭제합니다.
  • 전자 파일 형태의 개인정보는 데이터베이스에서 다시 조회하거나 재생할 수 없도록 삭제합니다. 데이터베이스 백업본을 만든 경우, 백업본은 만든 뒤 35일이 지나면 자동으로 삭제되므로 탈퇴한 회원의 정보도 백업본에서는 최대 35일 뒤에 사라집니다. 종이 문서로는 개인정보를 처리하지 않습니다.

3. 처리 위탁

  • 수탁자: Amazon Web Services Korea LLC(서울특별시 강남구 테헤란로 231) / 위탁 업무: 서버와 데이터베이스 운영, 데이터베이스 백업, 서버 접속 기록 보관(모두 대한민국 서울 리전)
  • 메일 발송(가입 인증·비밀번호 재설정 메일): 연결하기 전에 수탁자와 위탁 업무를 이 문서에 적습니다. 현재는 메일을 보내지 않습니다.

4. 국외 이전

서버, 데이터베이스, 백업, 서버 접속 기록은 모두 AWS 대한민국 서울 리전에 있습니다. 다만 화면 위쪽의 명령 바에 자연어 명령을 입력하면, 처음 한 번 아래 내용을 보여 드리고 동의한 경우에만 입력한 문장을 국외로 전송합니다(「개인정보 보호법」 제28조의8제1항제1호). 동의는 이 브라우저에 기록되며, 브라우저 저장소를 지우면 다시 묻습니다.

  • 이전하는 항목: 명령 바에 입력한 문장(최대 200자). 회원 번호·이메일 같은 회원 정보는 함께 보내지 않으며, 운영자는 문장을 저장하지 않습니다.
  • 이전 국가: 미국 / 시기와 방법: 명령을 입력할 때마다 암호화된 통신(HTTPS)으로 전송
  • 이전받는 자: TypeSafe AI, Inc.(미국, 개인정보 문의 privacy@typesafe.ai) / 이용 목적: 입력한 문장이 어떤 화면·종목을 뜻하는지 판별
  • 보유 기간: 이전받는 자는 서비스 제공에 필요한 기간 동안 보관하며, 입력한 문장을 AI 모델 학습에 쓰지 않는다고 밝히고 있습니다(TypeSafe 개인정보 처리방침, 2025년 11월 19일 개정).
  • 거부 방법과 효과: 동의하지 않으면 문장을 보내지 않고 메뉴 검색으로 찾습니다. 6자리 종목코드·명령어(예: 005930, HELP)는 전송 없이 동작합니다. 명령 바에는 개인정보를 입력하지 마세요.

해외 AI 리서치 기능(Anthropic, 미국)은 현재 쓰지 않습니다. 켜기 전에 이 문서를 고치고 그 기능을 처음 쓸 때 따로 동의를 받습니다. 동의하지 않아도 다른 기능은 그대로 이용할 수 있습니다.

5. 쿠키와 외부 자원

  • 서비스는 로그인 상태 유지와 위조 요청 방지를 위해 세션 쿠키 하나를 씁니다. 회원 번호와 무작위 세션 값이 서명된 형태로 들어 있으며, 광고나 방문 기록 추적에는 쓰지 않습니다. 로그아웃하거나 마지막 사용 후 7일(발급 후 최대 30일)이 지나면 서버에서 무효가 됩니다.
  • 브라우저 설정에서 쿠키를 막을 수 있습니다. 막으면 로그인이 필요한 기능은 쓸 수 없지만, 둘러보기와 백테스트는 이용할 수 있습니다.
  • 관심 종목 목록과 일부 화면 설정은 이용자 기기의 브라우저 저장소에만 두고 서버로 보내지 않습니다. 방문 분석·광고용 추적 도구는 쓰지 않습니다.
  • 로그인·가입·계정 화면과 이 문서는 외부 자원을 불러오지 않습니다. 그 밖의 일부 화면은 표시에 필요한 스크립트·글꼴을 외부 배포망(cdnjs.cloudflare.com, unpkg.com, cdn.jsdelivr.net, code.highcharts.com)에서 불러오며, 이때 해당 업체가 접속 IP 주소와 브라우저 정보를 받을 수 있습니다.

6. 이용자의 권리와 행사 방법

  • 이용자는 언제든지 자신의 개인정보 열람, 정정·삭제, 처리정지, 동의 철회를 요구할 수 있습니다.
  • 계정 설정 화면에서 비밀번호 변경, 모든 기기 로그아웃, 회원 탈퇴를 바로 할 수 있습니다.
  • 그 밖의 요구(예: 랭킹에서 빼 달라는 요청)는 아래 개인정보 보호책임자의 전자우편으로 보내 주세요. 가입한 이메일 주소로 보내 주시면 본인 확인에 도움이 됩니다. 요구를 받은 날부터 10일 안에 회신합니다.
  • 법정대리인이나 위임을 받은 사람을 통해서도 요구할 수 있습니다. 이 경우 「개인정보 처리 방법에 관한 고시」 별지 서식의 위임장을 내야 합니다. 열람과 처리정지 요구는 「개인정보 보호법」 제35조제4항, 제37조제2항에 따라 제한될 수 있습니다.

7. 만 14세 미만

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만은 가입할 수 없습니다. 가입할 때 만 14세 이상임을 스스로 확인받습니다. 만 14세 미만이 가입한 사실을 알게 되면 해당 계정과 개인정보를 지체 없이 삭제합니다.

8. 안전성 확보 조치

  • 관리적 조치: 개인정보 처리 권한을 운영자 1인으로 제한합니다.
  • 기술적 조치: 비밀번호·세션 값·인증 링크 값·Open API 키는 복원할 수 없는 해시로만 저장합니다. 데이터베이스는 인터넷에서 직접 접속할 수 없고 서비스 서버를 통해서만 접근합니다. 로그인·가입·비밀번호 확인 시도 횟수를 제한합니다. 오류 기록에 남기기 전에 토큰·비밀번호·키를 가립니다. 로그인 관련 화면에는 외부 스크립트를 쓰지 않고 콘텐츠 보안 정책(CSP)을 적용합니다. 전송 구간은 HTTPS로 암호화합니다.
  • 물리적 조치: 서버와 저장소는 AWS 대한민국 서울 리전의 데이터센터에 있으며, 물리적 출입 통제는 AWS가 수행합니다.
