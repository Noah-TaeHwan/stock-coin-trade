개인정보 처리방침

버전 2026-09-26(초안). 가입을 열기 전에 법률 확인을 거쳐 확정합니다. 가입할 때 동의한 버전은 계정에 기록됩니다.

1. 수집하는 개인정보

  • 회원 가입과 로그인: 이메일 주소, 닉네임, 비밀번호 해시(비밀번호 원문은 저장하지 않습니다)
  • 동의 기록: 동의한 처리방침 버전과 동의 시각, 만 14세 이상 확인
  • 이용 기록: 로그인한 날짜(하루 한 줄, 시각·기기·접속 위치는 저장하지 않습니다)
  • 서비스 이용 중 만들어지는 정보: 모의투자 주문·보유 내역, 관심 종목 메모, Open API 키(해시로 저장)
  • 오류 진단 기록: 오류가 난 요청의 IP 주소와 브라우저 정보(User-Agent)

2. 이용 목적

  • 회원 식별과 로그인, 메일 인증과 비밀번호 재설정
  • 모의투자·백테스트 등 서비스 기능 제공
  • 오류 진단, 부정 이용과 남용 방지(로그인·가입 시도 제한)
  • 주간 이용자 수처럼 개인을 드러내지 않는 이용 통계

마케팅 메일은 보내지 않으며, 이 목적 밖으로 쓰지 않습니다.

3. 보관 기간과 파기

  • 회원 정보와 서비스 이용 중 만든 정보: 탈퇴하면 즉시 파기합니다.
  • 가입 후 7일 안에 메일 인증을 마치지 않은 계정: 자동으로 삭제합니다.
  • 오류·외부 API 사용 기록: 90일이 지나면 삭제합니다. 탈퇴하면 먼저 회원과의 연결을 끊습니다.
  • 서버 운영 로그(Amazon Web Services CloudWatch): 30일 보관 후 자동 삭제됩니다.
  • AI 기능 사용 비용 기록: 월 예산 관리를 위해 남기되, 탈퇴하면 회원과의 연결을 끊어 누구의 기록인지 알 수 없게 합니다.

4. 처리 위탁과 국외 이전

  • Amazon Web Services(대한민국 서울 리전): 서버 운영과 데이터 보관
  • 메일 발송 서비스: 연결할 때 업체와 이전 항목을 이 문서에 적습니다.
  • 해외 AI 서비스(Anthropic, TypeSafe, 미국): 해당 기능을 켜기 전에 이 문서를 고치고 다시 동의를 받습니다. 지금은 사용하지 않습니다.

5. 이용자의 권리

  • 계정 설정 화면에서 비밀번호 변경, 모든 기기 로그아웃, 즉시 탈퇴를 할 수 있습니다.
  • 그 밖의 열람·정정·처리 정지 요청은 아래 문의처로 보내 주세요.

6. 만 14세 미만

만 14세 미만은 가입할 수 없습니다.

7. 안전성 확보 조치

  • 비밀번호는 복원할 수 없는 해시(bcrypt)로만 저장합니다.
  • 로그인 세션은 서버에서 확인하며, 로그아웃하면 즉시 무효가 됩니다.
  • 전송 구간은 HTTPS로 암호화하고, 관리 기능은 운영자만 쓸 수 있습니다.

8. 문의

문의 주소는 확정 때 적습니다.

9. 투자 조언이 아닙니다

이 서비스는 계산과 출처를 보여 주는 도구이며, 투자 권유나 조언을 하지 않습니다.
